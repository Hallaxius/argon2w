# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/Hallaxius/argon2w/security/advisories/new). Do not disclose unpatched vulnerabilities in a public issue or discussion.

Include the affected package version, runtime, impact, and a minimal reproduction where possible. Use synthetic passwords and data; never send real passwords, production PHC strings, secrets, tokens, or customer data.

## Supported versions

The latest version published to npm is the supported release. Check the [npm package page](https://www.npmjs.com/package/@hallaxius/argon2w) for the current version and update before reporting an issue.
